## 📌 Sobre o Projeto

O **SenaiPet-JS** é uma aplicação web voltada para o gerenciamento e agendamento de serviços de pet shop (como banho, tosa e consultas veterinárias). O projeto foi desenvolvido com foco em praticidade e usabilidade, aplicando conceitos fundamentais de desenvolvimento web frontend com JavaScript.

---

## ✨ Funcionalidades

- 🐶 **Cadastro e Listagem de Pets:** Registrar informações dos animais de estimação.
- 📅 **Agendamento de Serviços:** Marcação de horários para serviços de pet shop.
- 📋 **Gerenciamento de Atendimentos:** Visualização e organização das solicitações.
- 🎨 **Interface Intuitiva:** Layout simples e amigável para navegação do usuário.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação da aplicação web.
- **CSS3:** Estilização e design responsivo.
- **JavaScript (ES6+):** Lógica da aplicação e manipulação do DOM.
